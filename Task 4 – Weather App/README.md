# 🌦️ Task 4 – Weather App

A Python-based Weather Application developed using the **OpenWeatherMap API**.

This project includes both a **Beginner Command-Line version** and an **Advanced GUI version**.

---

## 📌 Project Overview

The Weather App allows users to enter a city name and retrieve real-time weather information using the OpenWeatherMap API.

The project was developed in two levels:

- **Beginner Version** – Command-Line Interface (CLI)
- **Advanced Version** – Graphical User Interface (GUI)

---

# 🟢 Beginner Version

The beginner version runs in the terminal and provides current weather information for a city entered by the user.

## Features

- Enter a city name
- Retrieve current weather information
- Display temperature in Celsius
- Display temperature in Fahrenheit
- Display humidity
- Display weather condition
- Display wind speed
- Handle empty city input
- Handle city-not-found errors
- Handle invalid API key errors
- Handle connection errors
- Handle request timeout errors
