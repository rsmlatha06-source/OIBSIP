# BMI Calculator

## Description
This is a Python command-line application that calculates a user's Body Mass Index (BMI) based on weight and height.

## Features
- Accepts weight (kg) and height (m) as input
- Calculates BMI using the standard formula
- Displays BMI rounded to 2 decimal places
- Classifies BMI into:
  - Underweight
  - Normal
  - Overweight
  - Obese
- Handles invalid input using exception handling
- Prevents zero and negative values

## Formula

BMI = Weight / (Height × Height)

## Technologies Used
- Python

## How to Run

1. Open `bmi_calculator.py`
2. Run the program.
3. Enter your weight in kilograms.
4. Enter your height in meters.
5. View your BMI and health category.

## Example

Input:
```
Weight: 60
Height: 1.65
```

Output:
```
Your BMI is: 22.04
Category: Normal
```
